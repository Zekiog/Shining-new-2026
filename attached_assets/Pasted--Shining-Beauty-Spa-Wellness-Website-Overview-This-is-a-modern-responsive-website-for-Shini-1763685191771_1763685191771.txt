# Shining Beauty Spa & Wellness Website

## Overview

This is a modern, responsive website for Shining Beauty, a luxury spa and wellness center in Adana, Turkey. The site serves as a digital storefront showcasing services (spa massage, skincare, body treatments, nail art), providing booking capabilities, displaying Instagram content, and offering informational blog posts. Built with vanilla HTML, CSS, and JavaScript, the site emphasizes visual elegance, SEO optimization, and user-friendly navigation with full dark mode support.

**Latest Update (November 21, 2025):** The website has been enhanced by merging two different structures, combining the best features of both versions. All images now use local assets, dark mode toggle functionality has been implemented, and the site is production-ready.

## User Preferences

Preferred communication style: Simple, everyday language.

## System Architecture

### Frontend Architecture

**Technology Stack:** The application uses vanilla HTML5, CSS3, and JavaScript without any frameworks. This decision provides maximum simplicity and performance for a static content website.

**Styling Approach:** The project employs a hybrid CSS strategy:
- Custom CSS with CSS Custom Properties (CSS variables) for theming
- Tailwind CSS utility classes (via output.css) for rapid styling
- Design system based on semantic color tokens that map to primitive colors

**Rationale:** This approach balances design consistency (through the token system) with development speed (Tailwind utilities) while maintaining full control over custom components.

**Theme System:** A comprehensive dark/light mode implementation using CSS custom properties:
- Automatic detection via `prefers-color-scheme` media query
- Manual toggle with localStorage persistence
- Color tokens organized into primitive (base colors) and semantic (contextual) layers
- Separate background color variants for different sections

**Component Structure:**
- Header with logo, navigation, and theme toggle
- Hero section with video background
- Service cards with detailed information (benefits, pricing, packages, contraindications)
- Instagram feed integration
- Blog section
- Contact/appointment forms
- Footer with social media links

**Responsive Design:** Mobile-first approach using CSS media queries and flexible grid layouts.

### Data Management

**Service Data:** Stored as JavaScript objects in `app.js`, structured with:
- Service metadata (ID, name, description, images)
- Pricing information (range and specific package prices)
- Benefits and contraindications arrays
- Duration specifications

**Rationale:** For a spa website with relatively static service offerings, client-side data structures provide immediate load times without requiring a backend. Future migration to a CMS or database would be straightforward given the structured data format.

**Content Organization:** Multi-language ready infrastructure (Turkish primary, English support) suggests planned internationalization.
